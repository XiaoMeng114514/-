# 🌌 宇宙霸主：球球大作战

> **Developer**: CN江南  
> **Version**: 1.1.0 (Signature Edition)

一款基于 HTML5 Canvas 的高性能多人在线战术竞技（IO类）游戏演示。本项目由 **CN江南** 深度优化，集成了丝滑的物理引擎、炫酷的粒子特效以及多端适配能力。

![Platform](https://img.shields.io/badge/platform-PC%20%7C%20Mobile-green.svg)
![Dev](https://img.shields.io/badge/Developer-CN%E6%B1%9F%E5%8D%97-blue.svg)

## ✨ 核心特性
（游戏仅占用27.7KB空间）

### 🎮 深度游戏机制
* **泰坦降临**：随机刷新巨大的 AI 机器人，带来 Boss 战般的压迫感。
* **宇宙霸主**：当球体直径达到 **5000** 时，你将加冕为王，赢得胜利。
* **复活系统**：被吞噬后保留 **80%** 体积，并在安全区重生，快速复仇。

### 🎨 极致视听
* **丝滑运镜**：摄像机跟随采用 Lerp 算法，杜绝画面抖动。
* **Game Juice**：拥有生物呼吸感、进食弹性动画、击杀粒子爆炸等丰富细节。
* **动态音效**：Web Audio API 实时合成音效，无需加载外部资源。

## 🥚 彩蛋与隐藏指令 (Secret Easter Eggs)

作为开发者 **CN江南** 的特别呈现，游戏中埋藏了多个神秘彩蛋：

### 1. 开发者专属彩蛋 (New!)
* **触发方式**：在名字框输入 **`CN江南`**。
* **效果**：激活**满屏专属水印模式**，整个宇宙将被打上开发者的烙印。

### 2. 名字彩蛋
| 输入名字 | 模式 | 效果 |
| :--- | :--- | :--- |
| `Rainbow` | **炫彩模式** | 球体颜色七彩循环闪烁 |
| `Ghost` | **幽灵模式** | 球体变为半透明隐身状态 |
| `Flash` | **闪电侠** | 移动时拖出粒子尾焰 |

### 3. 上帝模式 (God Mode)
* **触发**：在主菜单连续点击标题 **“🌌 宇宙霸主”** 10 次。
* **效果**：开局初始半径直接变为 **100**（普通为30），开局即无敌！

## 🚀 如何开始

1.  下载 `index.html`。
2.  使用 Chrome / Edge / Safari / Firefox 直接打开。
3.  在主菜单输入名字，点击“开始征途”。
